# Архив документации Corporator

Здесь лежит история: паспорта закрытых фаз и снятые планы. Сохранено, чтобы можно было найти, почему решение приняли и чем этап закрылся.

Пометки «архив» внутри текста не работают: агент открывает файл по имени. Поэтому архив отделён физически.

Это **не ТЗ**. Не открывать как задание. Не исполнять повторно. Действующий канон — `docs/CANON.md`. Файл, не перечисленный там, — архив. Ссылки внутри архивных файлов не чинить: они заморожены как были.

## Группы

- `reports/` — паспорта T/C/L/M/G/P/V/V3/R_V закрытых фаз.
- `plans/` — снятые планы фаз: картинка V0–V12, клеточный V3, код, live, v1.1, деньги, выход, TZ рендера и арта, разборы карты.
- `BRIEF.md` — раннее ТЗ; сам себя объявляет не каноном.

Агенту, который открыл файл из этой папки: остановиться и вернуться в `docs/CANON.md`.
