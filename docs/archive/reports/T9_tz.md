# 3. АРХИТЕКТУРА, КОТОРУЮ НАДО РЕАЛИЗОВАТЬ (принята, не обсуждается)

## 3.1 Пять законов экрана

Это ядро шага. Они должны быть записаны в `docs/SCREENS.md` §1 и каждый закреплён правилом линтера.

**Закон A. Отказ выводится, а не пишется.** У элемента нет списка отказов, написанного руками. У элемента есть список **капабилити-токенов** `requires`. Каждый токен — строка реестра `capabilities` с полями `code` (код из `content/params/codes.json`), `tier` (целое, порядок показа), `kind` (`blocking` | `warning`), `predicate` (формула на ключах пака), `src`. Полная матрица «экран × элемент × коды отказа в порядке показа» — **производная**, считается генератором и печатается в `content/out/GENERATED.md`. Новый отказ на кнопке = добавление токена в `requires`, а не новый код в клиенте.

**Закон B. Показывается один блокирующий код, остальные — списком в тултипе.** Порядок тотальный и детерминированный: сортировка по `(tier, token)`. Блокирующий код элемента — первый упавший `blocking`-гейт по этому порядку. Внутри одного элемента минимальный `tier` среди `blocking`-гейтов **уникален** — иначе сообщение неопределённо.

**Закон C. Порядок гейтов идёт от постоянного к сиюминутному.** Тиры фиксированы (значения `tier` берутся из реестра `capabilities`, в файле они хранятся, но их взаимный порядок проверяется правилом):

| tier | группа | смысл | токены → коды |
|---|---|---|---|
| 20 | scope | фича вообще есть в v1 | `v1_feature` → `FEATURE_NOT_IN_V1` |
| 30 | unlock | открыто ли | `city_level` → `CITY_LEVEL_TOO_LOW`; `district_open` → `DISTRICT_LOCKED`; `stake_threshold` → `STAKE_BELOW_THRESHOLD`; `tier_unlocked` → `TIER_NOT_UNLOCKED`; `stake_mult` → `STAKE_MULT_SHORT`; `node_side` → `NODE_SIDE_LOCKED`; `merge_free` → `MERGE_MATCHING_BLOCKED`; `season_qualified` → `PRIZE_NOT_QUALIFIED`; `season_stake` → `PRIZE_STAKE_REQUIRED` |
| 50 | funds | есть ли чем платить | `capital` → `NOT_ENOUGH_CAPITAL`; `corp` → `NOT_ENOUGH_CORP` |
| 70 | limit | сколько уже взято | `bank_limit` → `BANK_DAILY_LIMIT_REACHED`; `fragment_pool` → `FRAGMENT_POOL_EMPTY` (warning); `fragment_city_cap` → `FRAGMENT_CITY_CAPPED` (warning); `prize_pool` → `PRIZE_POOL_EMPTY` (warning); `season_open` → `SEASON_SETTLED` (warning) |

Причина порядка: игрок должен видеть **фундаментальный** блокер, а не сиюминутный. «Не хватает Capital» на закрытом районе — дефект доверия: игрок пойдёт зарабатывать деньги вместо того, чтобы стейкать.

Список токенов выше — минимальный обязательный. Если по ходу инвентаризации нужен ещё токен — добавляй строкой в реестр с `src` и `why`, но **новый код** заводи только если ни один существующий не подходит, и объясни это отдельным пунктом в разделе расхождений.

**Закон D. Число на экране не хранится, а ссылается.** У каждого поля панели обязателен `derived_from` — точечный путь в собранный пак (`<section>.params.<key>`, `<section>.derived.<key>`, `generated.<...>`), который **резолвится** при сборке. Числового литерала в полях панелей быть не может. Именованный пример из BRIEF: дневной лимит банка — не константа уровня, а `min(лестница банка, доля глубины пула)`.

**Закон E. Клиент не считает экономику** (`HUD.md` §8). У каждого поля `source` из белого списка `client_allowed_sources` = `{server, client_clock, client_format}`; экономические величины — только `server`. `client_clock` — часы города и обратный отсчёт плашки банка; `client_format` — SI-суффикс и форматирование (`HUD.md` §3).

## 3.4 Генератор `content/screens.py`

Чистый модуль, стиль как `content/fragments.py` / `content/seasons.py`. Только целые. Никаких `random`, `time`, `datetime`, сети, чтения файлов вне пака. Никаких экономических литералов (правило L45 расширяется на этот файл — добавь `screens.py` в его список файлов). Публичная функция `build_screens(data, generated) -> dict`, вызывается из `content/build.py` строкой `generated["screens"] = screens.build_screens(data, generated)` .

Обязательные производные:
- `action_gate_order[action_id]` — список токенов, отсортированный по `(tier, token)`; рядом список кодов в том же порядке.
- `blocking_code[action_id]` — код первого `blocking`-гейта; `None`, если гейтов нет (навигация).
