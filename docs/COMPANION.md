# Компаньон

Канон NFT-компаньона Corporator. Механика — `DESIGN.md` §5.14 / §5.4 / §5.6. Широкие таблицы — `content/out/GENERATED.md` секции «T8: …», команда `python content/build.py`. Чистая функция — `content/companion.py`. Проводка в тик — **T11**. Экраны — **T9**. Снимок цены вызова — **T12**.

---

## 1. Чем компаньон является и чем не является

Компаньон продаёт **внимание**, не преимущество. В v1.1 это автопилот из трёх неспендящих команд, советник (LLM снаружи тика), журнал и личность. Прямого множителя к выходу нет (`docs/archive/BRIEF.md` §2).

Единственная разрешённая строка — `idle_reduction_bps`; величина — `companion_idle_relief_bps`, не новый ключ и не новый код (как Scientist в R-T5-5). На остальных двенадцати ключах — ноль.

Компаньон **не** является: мэром, кошельком, минтом Capital, удлинением окна оффлайна, долей в фонде зарплат, краном фрагментов или призов.

Потолок холдера — человек, играющий идеально: аптайм ≤ `uptime_optimizer_bps`. Окно оффлайна компаньон не двигает. Величина режет `residual_idle_bps` через `mul_remainder` и не пробивает пол; окно A пересчитывается вместе с флагом (`L143`, `L311`).

## 2. Реестр команд

Разрешённые и запрещённые — **разные словари**, пересечение пусто. Таблица — GENERATED «T8: реестр команд».

Живые: `seat_agent` (пересадка уже нанятого в уже построенный свободный слот, `DESIGN.md` §5.6), `set_objective` (смена задачи со следующего тика, §5.9) и `set_manager_focus` (выбор контура Manager, §5.7; роль жива с G2).

Запрещённый список покрывает стройку, найм, стейк, кошелёк, клейм, research, открытие района, respec. Причина по каждому — `reason_kind`: spend / wallet / stake / irreversible / v1_1.

## 3. Лимиты частоты

Максимум — **одна команда на агента на тик**: тик читает одно состояние `(seat, objective)`. Вторая команда в том же тике — no-op. Суточная граница — производная `ticks_per_city_day × slots_cap`, оценка сверху, не настройка. Ни одно из этих чисел в `companion.json` не хранится.

Частота советника выводится из расписаний, не назначается:

```
advisor_calls_per_city_day := |{ h mod ticks : h ∈ open_hour/close_hour всех time.schedules } ∪ { efficiency_recalc_hour }|
advisor_cooldown_city_hours := ticks_per_city_day // advisor_calls_per_city_day   (≥ 1)
```

`close_hour = ticks` даёт час `0` и не добавляет седьмой слот. Смысл: советник говорит, когда меняется расписание города. Оба числа — derived. Неиспользованные вызовы не накапливаются (`companion_calls_carry_over = 0`). Очередь на холдера — глубина 1; вторая просьба при живой первой → `COMPANION_QUEUE_FULL`, состояние не меняется. Числа — GENERATED «T8: лимиты и производные».

## 4. Автопилот как чистая функция

`content/companion.py.plan(state, data)` — чистая, целые, без `random`, без системного времени, без сети. Считается на границе тика **до** тика. Выход — записанный вход тика, как сэмпл цены §2.3. LLM в автопилоте нет (`policy_kind = deterministic`). Тай-брейк лексикографический по `(priority_index, building_id, agent_id)`.

Политика — таблица строк в `companion.json.policy`. Новое поведение = новая строка, не новый код. Условия: закрытое расписание; `IDLE_WRONG_ROLE`; дефицит energy при Overclock; профицит energy — вернуть Overclock; простой входов у логиста (Route / Stockpile). Ни одного числа из другого файла. Таблица — GENERATED «T8: политика автопилота».

`DecisionRecord` layout не меняется (владелец T11, §6.1). Команды живут во входах тика; журнал — серверное представление над ними.

## 5. Исчерпание окна оффлайна

Окно кончилось — очередь замерзает (`companion_carry_over = 0`). Журнал пишет `COMPANION_WINDOW_CLOSED` с часом города. Молчаливого нуля нет (`DESIGN.md` §5.3). При заходе догон (T11) применяет **записанные** команды как записанные: `companion_replan_on_login = 0`. Иначе это скрытое удлинение окна MSFT, и реплей §6.3 не сходится.

## 7. Советник и стоимость инференса

Единица канона — вызов (`DESIGN.md` §5.2). Холдер тратит `advisor_calls_per_city_day` вызовов советника за сутки города. Суточная сводка (один вызов на город) — общий расход, не расход компаньона. Отказ провайдера → шаблон (`on_provider_fail = template`).

Доллар — **интервал** из утверждения §5.2, не замер. Точка ждёт `companion_llm_price_snapshot` (T12). Проба «10 000 холдеров» = `calls × BPS`, не второе хранимое 10000. Таблица — GENERATED «T8: стоимость инференса».

## 8. Почему бонус режет простой, а не выход

«Бонус растит пирог: меньше простоя» (`docs/archive/BRIEF.md` §2) в модели T2/T3 упирается в **окно оффлайна**. Величина на `idle_reduction_bps` режет `residual_idle_bps` через `mul_remainder` и не опускает его до нуля: пол держится, `uptime_optimizer_bps` не пробивается. Окно A пересчитывается вместе с флагом (`L143`, `L311`). **R-T8-1**.

Это не разбавление фонда: строка не трогает `output_bps`. Предикат форточки T5.6 включает `source_kind = companion`, чтобы +700 на `output_bps` падал на L77. **R-T8-4**.

Флаг `companion_rows_live=1` только со свидетелем рекаунта окна A (правило **L143**, как `season_prizes_live` / L115). Поднятие без свидетеля даёт величине резать `residual_idle_bps`, сдвигает вход полос T2 и делает окно A недействительным. Свидетель аптайма читает величину через `mul_remainder`, не флаг (L140).

## 9. Защита ветки MSFT

`offline_cap_hours` — собственность Automation (`DESIGN.md` §4.2). Компаньону запрещена строка на этом ключе **даже с нулём**: ключ не появляется в его params и rows. Компаньон **заполняет** окно, MSFT **удлиняет** окно. У холдера с открытым Automation ценность ветки растёт (длина × качество заполнения).

---

## 10. Краны NFT

`prize_nft_share_bps = 0` и `fragment_nft_share_bps = 0`. G6 зафиксировал ноль с причиной: `companion_revenue_live` остаётся 0, чтобы L128 не замолкал на кране; `nft_proceeds_sink = inference_bill`. Выручка NFT сначала закрывает счёт за инференс; счёт растёт линейно с холдерами. Направить её в пул фрагментов или призов — обещание доходности, которое протокол не удержит. Сплит `protocol_fragments_bps` / `protocol_prizes_bps` = 10000 / 0 не двигается. **R-T8-5**, **L312**.

---

## 11. Антисивил и демо

Владение NFT — записанный вход, fail-closed. Устаревшее чтение выключает автопилот (`hold_stale_action = off`, `COMPANION_HOLD_STALE`). Как молчание фида §2.3: отказ внешнего источника даёт игроку меньше, а не больше.

Демо-город без кошелька — без компаньона: `demo_companion = 0`, код `DEMO_NO_COMPANION`.
