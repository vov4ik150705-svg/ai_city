# Контракт API

Канон REST и WebSocket Corporator. Механика — `DESIGN.md`. Экраны — `docs/SCREENS.md`. Хосты — `docs/ARCHITECTURE.md`. Командная поверхность **выводится** из `screens.json`, не проектируется.

Широкие таблицы — маркеры `<!-- GEN:... -->`, секции пака «T12: …», команда `python content/build.py`.

---

## §1. Конверт

Каждый ответ несёт `city_time`, `tick_index` (производный), `pack_hash`, `rules_version`. Клиент с другим паком узнаёт это из конверта.

Отказ на действие игрока — HTTP `409`, тело `{code, slots, city_time}`. Текста на проводе нет: код плюс подстановки, текст рендерит клиент из `content/strings/ru.json`. Поле `message` запрещено. `L248`.

Транспортные коды — категория `transport` в `codes.json`. Ни один не `idle`, ни один не в `requires` элемента, ни один не `DecisionRecord.reason`. `L247`. `RENDER_NO_GPU` — код состояния клиента (нет WebGL), не транспорт и не reason записи.

## §2. Команды

Множество `POST /command/X` ≡ множество различных `commit:*` в `screens.json`. Биекция в обе стороны. Ручной список путей запрещён. `L232`. `derived.command_endpoints`. `commit:build` / `POST /command/build` в проводе ещё несут `build_place` (`R-V-55`, долг `docs/reports/PLAN_ISLAND.md` §5): посадка лот-плитки на пустой тайл. Живой канон — свободный авторский якорь (`R-V-100`). Вода, берег, дорога и занятый лот — `BUILD_TILE_ILLEGAL`.

Заглушка `v1 = stub` отвечает `FEATURE_NOT_IN_V1` и ничего не меняет: `spend = none`. `L234`.

`screen_id` не встречается ни в одном пути. Эндпоинтов «на экран» нет. `L235`.

Каждая мутирующая команда несёт `intent_id` и `expected_city_time`. Повтор возвращает первый результат и `API_INTENT_REPLAY`. Устаревшая `expected_city_time` — отказ. `L249`.

Лимит команд выводится: `2 × slots_cap`, не хранится. `L250`.

`commit:claim_prize` отвечает по каждому активу корзины (`prize_assets`): атомы на тикер, не одно число `$CORP`. Срезка доли — `PRIZE_SHARE_CAPPED[cap]`. `seasons.prize_basket` живёт в канале aggregate; ETH в пути, `$CORP` vault и ETH студии — в канале price. Нового канала нет.

## §3. Чтение и REST/WebSocket

`GET /city/{city_id}/state` отдаёт снимок из `state_sources`: каждый источник — ровно одна секция. Экран — забота клиента. Контракт REST и WebSocket — этот документ. Секция `log.events` — `{ rows }` с бейджем, корнем и CID; Verified только когда оба поля непусты.

<!-- GEN:api.snapshot -->

`GET /pack/{pack_hash}` отдаёт неизменяемый `content/out/pack.json`. Кеш — `immutable`. Клиент грузит этот пак, затем `GET /city/{city_id}/state`; без `city_time` в конверте экономического HUD нет.

`GET /ready` отдаёт `pack_hash` и `migration_version` в том же конверте и наблюдения метрик с `observe_src`; ни одно не равно порогу пака. Реплика без блокировки тика отвечает на GET и не шагает город.

## §4. Каналы

Пять классов частот экранного/API-контракта, ни одного шестого. Канала часов нет:
часы и плашка банка считаются локально. Каждый `state_source` — ровно один канал.
Экономический источник `source = server`. Каденция канала цен равна периоду сэмплера,
не хранится. `L236` `L237` `L238`.

<!-- GEN:api.channels -->

Пульс сокета — `ws_heartbeat_s`: три пульса внутри одного сэмпла. Путь сокета — `path_rules.ws`.

## §6. Идемпотентность и пакет

`intent_id` уникален у клиента. Сервер хранит `(city_id, intent_id) → результат`. Версионирование пака — `docs/CONTENT.md` §5: опубликованный пак не мутирует, сверка `pack_hash` падает закрыто.

Срок ваучера банка выводится из длины тика. `L258`.

---

## §7. Идентичность

Читает кто угодно: снимок города, пак, ready и сокет. Пишет только владелец: мутация несёт сессию в `Authorization`, `city_id` берётся из сессии, не из тела. TTL сессии и nonce — производные `session_ttl_s` и `nonce_ttl_s`. Нет сессии — `API_UNAUTHORIZED`.
