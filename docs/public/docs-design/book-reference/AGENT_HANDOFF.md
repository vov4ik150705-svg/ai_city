# Задание агенту интеграции: How the island works

Собери публичную книжку Corporator из этих готовых 11 комплектов по docs/reports/GAME_BOOK_CONCEPT.md. Это готовые утверждённые арты и воспроизводимые макеты, а не задание на новую генерацию.

## Главное правило

Внутри каждой папки NN-<anchor>-ready находится ОДИН art.png. Вся сцена, рисунки зданий и людей, облака, синие пометки, стрелки, метафоры, подписи карточек и числа уже в этом PNG. Просто поставь его на чисто белую поверхность панели. Ничего не рисуй заново, не вырезай отдельные элементы, не заменяй встроенные подписи HTML/SVG и не накладывай их второй раз. Не генерируй новый арт или полный мокап.

Отдельным HTML остаются только eyebrow, заголовок, основной абзац, сноска, ссылка в Handbook, настоящий логотип и оболочка/навигация. Точные английские тексты, переносы и координаты есть в index.html, book.css, HANDOFF.md и manifest.json каждой папки.

Сравнивай реализацию с mockup.png именно этой папки. В нём использован тот же art.png, SHA-256 записан в manifest.json. На белом фоне прозрачные свободные области сливаются с панелью. Сохраняй непрозрачные белые внутренние поверхности нарисованных предметов.

## Размещение

База desktop 1672×941, панель1400×860, x135 y64, border-box, белый фон, рамка2px #B7DCFF, radius24. Точные left/top/width арта различаются между страницами: бери их из manifest.geometry и HANDOFF. Сохраняй height:auto и исходный аспект. Не применять crop, object-fit:cover, фильтры, tint, opacity, удаление фона или растягивание по осям. Генератор выдал несколько немного отличающихся нативных размеров — они уже учтены в проверенной сборке. Не приводить их механически к одному размеру.

Шрифты Caveat и Roboto с лицензиями включены. Возьми начертания и метрики из book.css. Логотип — brand-mark.png, не перерисовывать.

На телефоне <=900px используется отдельная вертикальная раскладка: живой текст, целый PNG, сноска и ссылка. Нижняя навигация фиксирована. На странице11 у неё два ряда, чтобы две кнопки и11 точек не пересекались. Эталонные мобильные скриншоты375×812 и полная прокручиваемая страница лежат в комплекте. Тап по арту открывает просмотр на белом фоне с увеличением/прокруткой, закрытием и pinch; это необходимо для чтения встроенных пометок. Не заменять мобильную версию простым уменьшением desktop.

## Интеграция в сайт

Используй существующую шапку и фон сайта. Книжка открывает /docs в режиме In pictures; переключатель Handbook показывает существующий справочник. Страницы имеют якоря: island, people, shift, money, the-tank, fills, way-home, keys, your-key, seasons, before. Все11 точек, Previous/Next, стрелки клавиатуры и сохранение последней страницы должны работать. Возвращение из Handbook восстанавливает место. Прямой адрес /docs#keys открывает08. Никаких Skip guide или крестика в панели.

More in the handbook ведёт к конкретной главе/разделу из manifest.ref. В локальной сборке handbook.html — только зеркало исходных глав для проверки ссылок. На сайте используй существующий renderer, правильные chapterHref и scrollToId; не переносить локальное зеркало как новый справочник.

Все английские тексты сверены с концепцией, числовые значения — с текущим content/out/pack.json. Основной HTML при интеграции привяжи к актуальным параметрам по таблице §5 концепта. Числа внутри PNG зафиксированы и не подменяются динамически. Если пак изменился, сообщи о необходимости обновить соответствующий арт, не рисуй поверх новые значения.

На11 вместо Next — две настоящие кнопки Play the demo и Read the handbook. В текущем apps/www/src/data/shell.ts URL демо отсутствует: локальная кнопка посылает corporator-book:demo и показывает подтверждение запроса. Подключи её к реальному существующему запуску демо; если его ещё нет, сообщи это владельцу. Не придумывай адрес и не выдавай локальное подтверждение за запуск игры.

## Проверка

Открой все11 страниц с включёнными локальными шрифтами и декодированными изображениями. Сверь с mockup.png, затем проверь телефон375×812, отсутствие пересечений текста/рисунка и навигации, переходы/прямые якоря, Handbook туда-обратно и увеличение арта. PNG в реализации должен совпасть с SHA-256 в manifest.json.

Готовый общий архив можно распаковать и открыть index.html. gallery.html показывает все11 финальных мокапов. В архивах нет отвергнутых вариантов. Эталонный стиль закреплён исходными BANK/Workshop в соседнем ethalons; при интеграции не менять стиль и не рисовать дополнительные декорации.
