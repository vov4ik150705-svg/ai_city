## 2. Характер движения

Движение — спокойное, точное, с мягким торможением. Оно ощущается как качественный интерфейс управления: нажатие получает ответ сразу, выбранное состояние хорошо читается, переход завершается быстро. Более выразительный эпизод допустим при первом появлении острова; частые действия делай короче.

Обязательные принципы:

1. Меняющееся содержимое движется, управляющие табы/селекторы сохраняют положение.
2. У каждого компонента одна основная идея движения; не складывай fade, scale, blur, rotation и parallax в одном переключении.
3. Повторное действие прерывает текущий переход. Последний выбор побеждает; очередь старых анимаций не проигрывается.
4. Цвет, рамка и aria-состояние выбора меняются сразу. Анимация содержимого не задерживает ответ кнопки.
5. Неанимированная версия остаётся полноценной и красивой.
6. Самые частые действия проходят за 160–260 ms. Длительные появления допустимы только для крупных иллюстраций при входе.

Не используй: scroll hijacking, инерцию всей страницы, перехват wheel для лендинга, обязательные pinned-scroll сцены, auto-carousel, автопереключение отраслей/агентов, мигающие свечения, bouncy spring, overshoot, cursor trails, магнитные кнопки, масштабирование текста, shimmer по всему экрану и непрерывное качание всех иллюстраций.

Неинтерактивная карточка не поднимается и не реагирует как кнопка. Не заставляй пользователя ждать завершения reveal, чтобы прочитать текст или нажать CTA.

## 3. Общие параметры

Согласуй новые параметры с существующими токенами `styles/tokens.css`. Вынеси настройки и повторяемые React-паттерны в маленький модуль, например `src/motion/`. Не размазывай магические длительности по компонентам. У новых параметров должен быть один нормативный источник, CSS и Motion должны давать одинаковое ощущение.

| Назначение | Длительность | Движение |
|---|---:|---|
| Hover интерактивного элемента | 120–150 ms | Цвет/рамка; иконка-стрелка вправо максимум 2–3 px |
| Press | 80–100 ms | Внутренний визуальный слой scale 0.985 либо translateY 1 px; область клика неподвижна |
| Выделение tab/segment | 180–220 ms | Линия/рамка перемещается; без прыжка ширины текста |
| Содержимое при выборе | 180–240 ms | Fade + y 4–8 px; изображение 240–300 ms |
| Tooltip | 100–140 ms | Fade + y 3–4 px; hover задержка 100–150 ms, focus/tap без задержки |
| Desktop dialog: вход | 240–280 ms | Панель y 10–12 px и scale 0.985 → 1; backdrop fade 160–180 ms |
| Dialog: выход | 160–200 ms | Обратное короткое движение; backdrop исчезает согласованно |
| Мобильное меню / компактная sheet | 220–260 ms | Панель y 8–16 px; выход 160–180 ms |
| Секция: первое появление | 360–480 ms | Opacity + y 12–18 px; иллюстрация не более 24 px |
| Смена страницы | 160–200 ms | Fade у содержимого; без масштабирования всей страницы |
| Смена главы Docs | 120–160 ms | Только лёгкий fade области article |
| Небольшая локальная смена высоты | 180–240 ms | Измеренная высота оболочки; не scale текста |
| Иллюстративная диаграмма при первом входе | 400–650 ms суммарно | Короткая последовательность групп; значения видны сразу |

Основной ease для входа: `cubic-bezier(0.22, 1, 0.36, 1)`; для переключений/выделения: `cubic-bezier(0.2, 0, 0, 1)`; для выхода — короткая ease-in, например `(0.4, 0, 1, 1)`. Допустим умеренный spring только для выделения, без заметного отскока. Stagger группы — 35–55 ms, суммарная задержка группы не больше 180 ms. В мобильной вертикальной колонке не заставляй нижние карточки ждать всю последовательность.

Это целевые параметры. Подстрой в указанном диапазоне после реального просмотра переходов. Не делай анимацию медленнее только ради демонстрации.

- Рамка выбранной миниатюры движется/появляется мягко; миниатюры не подпрыгивают.
- Сохрани `modelFrame` — масштаб и точку опоры разных зданий. Анимацию размещай на дополнительном wrapper, не перезаписывай уже используемый transform изображения.

`blocks/Rating.tsx`, `blocks/rating/Influence.tsx`, `Order.tsx`, `Factors.tsx`, `Calendar.tsx`, `styles/rating*.css`.

### K. Документация — тихий режим

`docs/DocsRoute.tsx`, `HandbookLayout.tsx`, `handbook/handbook.css`, `render/Blocks.tsx`.

- При смене главы article делает opacity fade 120–160 ms; sidebar и shell стабильны. Не применяй reveal к каждому абзацу, формуле, таблице, FAQ и длинной главе.

- Мобильный список глав вместо display none/block раскрывается локально за 180–220 ms; выбранная ссылка и Escape закрывают его. Если это inline disclosure, не добавляй ему modal focus trap. Не прокручивай пользователя к началу статьи при простом раскрытии списка.
- Previous/Next и ссылки на разделы используют правильную навигацию/scroll A5. Горизонтальная прокрутка таблиц и схем остаётся нативной, без wheel hijacking и анимации содержимого.
- `Diagram source` — лёгкая анимация height/fade только для существующего fallback details; сохраняй native summary/keyboard. Если fallback на текущих главах не показывается, не создавай его искусственно ради демонстрации.
- Lazy-loading Docs: не показывай долго пустую белую страницу. Можно prefetch модуля при намерении перейти в Docs и обеспечить спокойный нейтральный fallback с сохранённой геометрией, если загрузка задержалась. Он не имитирует документ или live data; shimmer не нужен.
- Рукописные SVG/линии можно один раз мягко проявить при входе главы. Не анимируй каждое ребро сложной схемы, не меняй геометрию и порядок смысловых связей.

## 5. Архитектура и жизненный цикл

1. Добавь верхнеуровневую MotionConfig с политикой reduced motion и маленькие общие helpers: reveal, panel transition, selection indicator, animated overlay. Избегай гигантского универсального компонента с десятками флагов.
2. CSS — для hover/focus/colors/tooltips. Motion — для presence, связанных смен контента и локального layout. Observer — для входа крупных групп. Не делай React setState на каждый pixel scroll.
3. `AnimatePresence` должен жить выше условного удаления. Сам animated child имеет стабильный key. Переходы не строятся на `setTimeout(duration)`; завершение — сигнал библиотеки/animation event с корректным cleanup.
4. Native `<dialog>` сохраняет top layer, Escape и focus semantics. Во время exit не вызывай `close()` и не снимай lock слишком рано. Сначала запрос закрытия/exit, затем реальное close/unmount и возврат focus. Повторный Escape/Close идемпотентен. При навигации прерывай устаревший exit безопасно. Не полагайся только на backdrop DOM-div: native `::backdrop` требует отдельной стратегии enter/exit.
5. Общая scroll-lock модель должна учитывать смену одного диалога другим. Сохраняй body styles, scrollY и scrollbar gap, восстанавливай после последнего закрытия. Старый cleanup не снимает новый lock. Используй `scrollbar-gutter` либо эквивалентную компенсацию; при закрытии страница не сдвигается по x/y.
6. Для crossfade/image transitions удерживай не более двух нужных слоёв, decoded image готовится до входа. Состояние desired отличается от displayed; устаревший resolve не побеждает последний выбор. Поломанная сеть/decode не блокирует контролы и закрытие.
7. Не перезаписывай существующие transform нормализации изображений, skew и fixed-nav scale. Добавляй отдельный motion-wrapper и проверь его влияние на clipping, sticky/fixed и tooltip.
8. Одновременно доступен один tabpanel/одна modal/одна глава. Выходящие DOM-слои — inert, aria-hidden, pointer-events none; focus никогда не остаётся внутри уходящего слоя. Автоматический focus не перескакивает во время движения при обычном mouse click по tab.
9. Новые timers, observers, subscriptions, RAF и временные ресурсы полностью убираются. Скрытая вкладка не запускает декоративное движение; loop только пока реально нужен. Не вводи постоянный `will-change` для всех карточек.
10. Преимущественно анимируй transform/opacity. Цвет небольших элементов допустим. Height — осознанное локальное исключение для disclosure/панели с небольшой разницей, измеренное ResizeObserver; не для всей страницы. Не анимируй большой blur, box-shadow всего экрана, left/top/width графика и CSS `transition: all`.

## 6. Reduced motion, чтение и быстрый ввод

- `prefers-reduced-motion: reduce`: parallax/settle/translate/scale/stagger выключены; reveal сразу виден; smooth scroll заменён auto; height меняется сразу. Допустим короткий opacity до 80 ms либо мгновенная смена.
- CSS и `motion/react` учитывают настройку вместе, включая изменение preference во время открытого сайта. Проверь JS-scroll в Industries — он сейчас явно smooth.
- Не добавляй вечную анимацию, требующую нового пользовательского управления Pause. Если всё же предложен ambient-эпизод, сделай его коротким конечным, завершающимся менее чем за 5 секунд, и выключай при reduced motion.
- Нажатия, клавиатурные стрелки, Escape, touch scroll, смена ориентации и browser history прерывают соответствующее движение безопасно.
- Активные состояния доступны через aria независимо от анимации. Финансовые данные, документы и ошибки не скрываются до появления красивого эффекта.

## 8. Приёмка: проверять поведение, не только скриншоты

Обязательные размеры: 1440×900, 1024×768, 390×844, 360×800. Дополнительно проверь границы 1150px и 900px, где меняются rail/sidebar. Проверь масштаб браузера 200%, touch и keyboard.

3. Menu open → close → open, Escape, Tab/Shift+Tab, Docs на текущей странице, переход в другую страницу. Никакого click-through и потерянного scroll lock.
4. Play → demo preview → Close, затем Play → wallet preview → Escape; быстро повторить. Один backdrop, без мигания и скачка страницы, focus возвращается к реальной исходной кнопке.
5. Все четыре Game HUD preview: открыть/закрыть, повторить после скролла на mobile. Позиция и focus сохраняются.

7. Industries/Tiers/Merges, Economy Enter/Work/Exit/Prizes: быстрые клики и arrows. Controls остаются на месте, высота не уводит выбранный tab за экран.

10. Все пять сотрудников, быстрый выбор, touch-scroll selector. Нет наслоения двух портретов/двух доступных панелей, пропорции и ноги/точка опоры не скачут.
11. Tooltip hover → переход в bubble, focus, tap/pin, Escape/outside click на mobile. Подсказки не обрезаны и не появляются на неверном элементе после смены панели.
12. Rating: три switches, три Efficiency значения, search/clear. Day/period значения соответствуют прежним формулам; анимация не создаёт данные пустого рейтинга.
