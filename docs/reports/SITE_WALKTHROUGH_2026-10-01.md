# Проход сайта Corporator — 1 октября 2026

Живой проход `http://127.0.0.1:5180/` (Vite, `apps/www`). Десктоп 1920×1080 и телефон 390×844. Клики по кнопкам, вкладкам, меню, книге и справочнику. API на `127.0.0.1:7460` в этот момент не слушал.

Это аудит, не список правок. Ничего в коде не менялось.

## Критичное

### 1. Портреты агентов иногда не появляются

Снято в том же дне: прямоугольник фигуры записан в `apps/www/src/data/agents.ts`, страница рисует картинку сразу и больше не сканирует пиксели.

Картинка не вставлена в страницу сразу. `Agents.tsx` сначала скачивает пять PNG, для каждого обходит каждый пиксель и находит непрозрачный прямоугольник (у файлов большое прозрачное поле). Пока этот обмер не записан в состояние, и большая фигура, и фото в карточке — `null`. Рамки карточек при этом уже нарисованы, поэтому секция выглядит как пять пустых скошенных плашек.

Пять файлов ждут друг друга: `Promise.all`. Упадёт один — не рисуется ни один. Ошибка выбрасывается пустым `catch`, повтора нет. До следующей полной загрузки страницы лица так и не появятся.

В первом проходе так и было: после перезагрузки, больше 6 секунд, у `.agents__stage` ноль картинок. Файлы при этом целые (`website/units/Engineer.png` 1024×1536 и остальные). На следующей чистой загрузке те же URL декодировались, и секция собралась: инженер стоит в кадре (около 475×712), в пяти карточках видны головы. Значит файлы не пропали. Пропал один заход обмера, и страница это не пережила.

Текст «every card below shows role, level, traits…» относится к правой панели (роль, здания, уровень, черты). Сама карточка снизу — только кроп портрета. Пока обмера нет, и панель с текстом есть, и карточки пустые.

### 2. Главные кнопки никуда не ведут

`destinations` в `apps/www/src/data/shell.ts` все пустые: demo, wallet, docs, x, risk.

Что происходит по клику:

- **Play now** (шапка, герой, футер, липкая полоса) открывает «How do you want to play?».
- **Try the demo** и **Connect wallet** открывают следующий диалог: «A verified game or demo destination has not been supplied. No wallet connects, funds move, or progress is recorded.»
- **Follow on X / Corporator on X** — то же про внешнюю ссылку.
- **How the economy works**, **Meet the agents**, **More on deposits / payroll / withdrawals / prizes**, **Voucher** — «The external documentation URL has not been supplied.»

Для незапущенного продукта честный тупик лучше фальшивого кошелька. Для игрока это всё равно мёртвые главные действия. Ссылку на X и переход «подробнее» в уже существующий `/docs/...` можно дать без запуска контрактов.

### 3. Рейтинг: провод к живым данным есть, в проходе API не был запущен

Правка на месте. Страница не подставляет выдуманные строки. В dev она запрашивает `http://127.0.0.1:7460/rating`. API отдаёт конверт с `rows` из живой доски `publicRatingRows`: один кошелёчный город на кошелёк, без демо, порядок Influence, затем Day GDP, затем меньший city id. Клиент читает `rank`, `wallet`, `influence`, `gdp`, `self`.

В этом проходе на 7460 никто не слушал. Браузер получил обрыв соединения (статус 0), таблица показала **Unavailable**. Это ветка «запрос не удался», не откат правки.

Если API поднят и кошелёчных городов нет, текст другой: **No wallet cities yet.** Если города есть, в таблице их ряды. Метка You на этом маршруте не появится: публичный `GET /rating` без сессии, `self` всегда 0.

## Баги

### Агенты и картинки

- Полоска **Wrong fit** есть как подпись и пустая дорожка. Заливки нет, это задумано (`fill: null`), но выглядит как сломанный бар.
- При первом переключении индустрии, пока PNG (~1,3–2,0 МБ) ещё едет, вместо здания на секунду виден alt-текст и значок битой картинки. После загрузки Finance Tower и Clearing House встают нормально. Скелетона нет. У Compute (AI Research Center) та же схема, просто файл успел прийти раньше.

### Здания

- **View 3D** открывается, WebGL-холст есть (City Hall, примерно 1100×693). Модель очень тёмная на тёмном фоне, в отличие от яркой карточки рядом. Диалог не закрывает колонку миниатюр: справа виден её скролл, слева обрезанный заголовок секции.
- Колонка из 18 зданий показывает около трёх. `scrollbar-width: none`. Остальные находятся стрелками или колесом, полосы прокрутки нет.

### Лидерборд

- Таблица замылена, по центру замок и текст **Leaderboard opens in**. Цифр и даты нет.
- Причина в данных: `leaderboardOpensAt = null`, фаза `locked`, а подпись всё равно «opens in». Фраза обрывается.

### Документы

- На первом развороте книги подписи справа на рисунке обрезаны («dark window…», «different light…»).
- Нижняя строка второго разворота («No AI inside…») сидит на кромке кадра и режется.
- В справочнике в теле есть маркер **[NEEDS CONFIRMATION]** — внутренняя пометка, видна читателю.
- Футер справочника при невыпущенном контракте пишет `$CORP 0x000....`. Футер маркетинговых страниц в том же состоянии пишет **Contract TBA**. Текст главы при этом говорит: пока адреса нет, и никакой адрес не официальный. `0x000....` этому противоречит.
- Страница «Page not found» — один заголовок. Домой можно только логотипом.

### Шапка

- На десктопе после любого скролла шапка уезжает вверх (`is-concealed`). Вернуть её можно, наведясь на верхнюю полоску. Пока читаешь длинную главную, Game / Leaderboard / Rating / Docs пропадают.
- На Leaderboard и Rating шапка — плоская голубая полоса: это обрезанный фон героя, не отдельный фон внутренней страницы.

## Что работает и выглядит цельно

- Герой: остров, небо, вывески City Hall / COINBASE / NVDA читаются, кнопки на месте.
- Индустрии: смена Compute → Finance меняет цвет заголовка, башню и список синергий. У Finance остаётся одна пара, Clearing House.
- Economy: панель Enter / Work / Exit / Prizes собрана, картинки на месте, вкладка не дёргает скролл.
- Rating ниже таблицы: переключатели факторов, 85% / 100% / 115%, график. Выключение GDP ÷ capex красит карточку, дневной счёт становится 0, период пересчитывается (в проходе вышло 222 459). Это объяснялка, не живой рейтинг.
- Поиск кошелька на Rating показывает кнопку очистки. Пока API лежит, состояние таблицы остаётся Unavailable, а не «ничего не найдено».
- Книга и справочник переключаются, главы в боковом меню есть, статус «ещё не запущено» в тексте главы честный.
- Мобильное меню открывается и закрывается. Горизонтальной прокрутки страницы нет.
- На маркетинговом футере контракт честно **Contract TBA**.

## Бэкенд

Сайт почти статический. Сеть есть в двух местах:

1. **Rating** — единственный запрос к API. Провод к живой доске есть. В проходе процесс на 7460 не был запущен, поэтому таблица показала Unavailable. См. §3.
2. **View 3D** — `fetch` модели здания с того же сайта, не с игрового API. Холст поднялся. Свет модели слабый. См. баг про 3D.

Игровой API (`/ready`, `/rating`, команды города) этим сайтом больше нигде не вызывается. Тик, касса и кошелёк здесь не проверялись: процессов на 7460 не было.

## Улучшения, не баги

- Сжать портреты и башни индустрий. Сейчас это PNG по 1,3–2 МБ, из‑за них первый показ вкладки мигает.
- Скелетон на месте башни и портрета, пока файл не декодирован. Не показывать alt как битую картинку.
- Шапка: прятать при скролле вниз и возвращать при скролле вверх, а не только по наведению на невидимую полоску.
- На 404 дать ссылку на главную и в справочник.
- Убрать `[NEEDS CONFIRMATION]` из публичного текста или заменить нормальной фразой.
- Скриншоты HUD в блоке Game (Overview и соседи) — старый макет с числами вроде 124 800 и 5 000. Для витрины это картинка, не живой счёт, но она расходится с текущим HUD. Лайтбокс ещё и вкладывает окно в окно: своя рамка плюс рамка на скриншоте.
- Колонке зданий вернуть видимый способ листать, не только спрятанное колесо.
- В 3D поднять свет и дать диалогу закрывать страницу целиком.
