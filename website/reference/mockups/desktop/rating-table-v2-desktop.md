# Rating table — desktop mockup v2

Дата: 2 октября 2026. Это предложение дизайна таблицы публичной страницы Rating, без изменения сайта. Изображение: `rating-table-v2-desktop.png`.

## Что показано

- Светлая карточка на текущем фоне `#F4F6F9`; белая поверхность, тонкие разделители, сдержанная тень.
- Четыре существующие колонки: место, кошелёк, Influence, Day GDP. Числа выровнены вправо; Influence выделен весом шрифта. Адреса используют моноширинное начертание.
- Поиск `Find a wallet`, отдельная кнопка `Find my rank`, копирование полного адреса.
- Строка своего кошелька: мягкий зелёный фон, полоска слева, подпись `You`. Цвет не является единственным признаком.
- Нижняя панель: диапазон результатов, выбор количества строк, Previous/Next, номера страниц, многоточие. Текущая страница выделена тёмным фоном; недоступные действия приглушены.
- Пример содержит 10 строк, условные 1,280 кошельков и 128 страниц. Надпись `Example data` обозначает демонстрационные данные. Первые шесть строк взяты из приложенного скриншота, остальные четыре добавлены только для макета.

Маленький заголовок Wallet standings нужен для автономного просмотра мокапа. При внедрении сохранить существующий главный заголовок страницы Who's ahead и не дублировать его.

## Поведение при внедрении

1. Поиск выполняется по полному адресу во всём доступном списке, до разбиения на страницы. При изменении запроса или количества строк перейти к первой странице.
2. `Find my rank` открывает страницу со строкой текущего кошелька и прокручивает к ней. Показывать кнопку только при известном текущем кошельке и найденной строке. Мокап не требует добавления подключения кошелька.
3. Номера мест остаются глобальными: на второй странице при 10 строках это 11–20. Порядок — каноничный рейтинг по Influence с действующими правилами разрешения равенства; стрелка заголовка обозначает этот порядок. Она не предлагает произвольную сортировку по GDP.
4. Выбор числа строк: 10, 25, 50. Количество страниц и диапазон результатов вычисляются по фактическим данным. При единственной странице не показывать лишние номера и многоточие.
5. Копирование использует полный адрес; иконка имеет понятное доступное имя, краткий ответ Copied и доступное сообщение об ошибке.
6. При переходе страницы панель управления остаётся на месте. Допустима лёгкая смена opacity содержимого за 120–160 ms; не анимировать каждую строку последовательно. Учитывать reduced motion.
7. Предусмотреть существующие loading/error/empty/no-match состояния. Пагинация в них не создаёт фиктивных результатов. Не вставлять примерные строки в production.
8. Таблица сохраняет семантику table; текущая страница имеет aria-current, недоступные кнопки disabled. Явный focus, удобные зоны нажатия, доступное объяснение Day GDP.
9. На телефоне поиск занимает полную ширину, Find my rank располагается следующей строкой. Четыре колонки помещаются в таблицу с локальной горизонтальной прокруткой при необходимости; числовые значения не обрезаются. Нижняя панель переносится: диапазон/Rows, затем компактные Previous / текущая страница / Next. Desktop-мокап не заменяет отдельную проверку мобильного решения.

## Генерация

Использован встроенный image_gen. Референс — приложенный владельцем скриншот текущей таблицы. Игровые иллюстрации, персонажи и логотипы не генерировались. Исходные файлы сайта не менялись.

Содержание промпта первого прохода: переработать таблицу в точный светлый desktop UI mockup; сохранить четыре колонки и первые шесть строк; добавить четыре демонстрационные строки, поиск, Find my rank, копирование, мягкое выделение You, Rows 10 и пагинацию 1/2/3/…/128; обозначить Example data; использовать цвета текущих токенов Corporator, Roboto-подобный текст и JetBrains Mono-подобные адреса; без наград, графиков, сезонов, дат и декоративных игровых объектов.
