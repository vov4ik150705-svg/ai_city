# Corporator — Dexscreener V9, объёмное название

По прямому уточнению владельца: одна крупная надпись CORPORATOR по центру, объёмные буквы, полноценный арт по всей ширине. Колонка действий, $CORP и монета из V8 убраны. Утверждённый X остаётся в ../v7-buildings/.

- `dexscreener-1500x500.png` и `.jpg` — финальный баннер.
- `dexscreener-3000x1000.png` — растровый мастер.
- `scene-clean-3000x1000.png` — сцена без рекламной надписи.
- `dexscreener-layered-master.ora` — три слоя: сцена, объёмное название и передние облака; совместим с Krita/GIMP.
- `dexscreener-editable-master.svg` — самостоятельный мастер с раздельными изображениями и скрытым редактируемым исходным текстом в игровом шрифте.
- `title-3d-generated.png` — исходный прозрачный рендер букв.
- `title-font-guide.png`, `title-font-mask.png`, `title-layout.json` — точная исходная форма надписи из оригинального игрового шрифта.
- `verification-report.md` — источники и пределы точности; `file-verification.json` — размеры и техническая проверка.

Сцена и объём букв созданы встроенным image_gen. Для формы букв использован игровой TT Octosquares Trial Condensed Black из проекта, не выбран новый шрифт. Готовый объёмный рендер — растровый слой: изменение исходного скрытого текста не перестраивает его автоматически. Раздельные слои можно перемещать, масштабировать и скрывать. Мастер не содержит отдельных 3D-моделей.

Промпты сохранены в соседних текстовых файлах. Референсы зданий и ролей — исходные наборы из ../v7-buildings/references/ и ../v4/references/, дополнительно оригинальный лист media/kit/buildings/finance_tower.png. Арт не назначен каноном. Ничего не публиковалось.
