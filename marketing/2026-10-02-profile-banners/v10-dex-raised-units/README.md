# Corporator — Dexscreener V10, юниты выше

Исправление по просьбе владельца: команда поднята над названием, чтобы были лучше видны лица, плечи, одежда и верхние части планшетов. Объёмное название и передние облака взяты из V9 без изменения графических слоёв.

Финал: `dexscreener-1500x500.png` и `.jpg`. Растровый мастер: `dexscreener-3000x1000.png`. Чистая сцена с поднятой командой: `scene-clean-3000x1000.png`. Дополнительно сохранён фон без команды: `background-3000x1000.png`.

`dexscreener-layered-master.ora` и `dexscreener-editable-master.svg` содержат четыре самостоятельных слоя: остров, команда, объёмное название, передние облака. Команду теперь можно перемещать независимо. В SVG сохранён скрытый текстовый источник в игровом шрифте. Готовое объёмное название — растровый рендер, оно не перестраивается автоматически при правке скрытого текста.

Сцена редактировалась встроенным image_gen; команда выделена в прозрачный материал тем же инструментом по предыдущему рендеру и оригинальным игровым ролям. Исходные игровые картинки юнитов отдельно на фон не вклеивались. Промпты сохранены рядом. Положение команды — в `layout.json`, результаты проверки — в `verification-report.md` и `file-verification.json`.

Предыдущий V9 сохранён. Утверждённый X не менялся. Ничего не публиковалось.
