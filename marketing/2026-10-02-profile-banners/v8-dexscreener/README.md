# Corporator — Dexscreener, название в облаках

Отдельная композиция для Dexscreener по просьбе владельца. Утверждённый баннер X находится в ../v7-buildings/ и не заменяется этим макетом.

Идея: город в глубине слева, пять агентов за большим названием CORPORATOR, облака вокруг нижнего края букв. На спокойном небе справа — точный оригинальный знак токена, $CORP и три игровых действия:
HIRE AGENTS.
UPGRADE BUILDINGS.
RUN THE ECONOMY.

Шрифт рекламной типографики: TT Octosquares Trial Condensed Black из website/fonts/tt-octosquares/. Он визуально сверён с присланным образцом и подключён в apps/www/src/styles/base.css как TT Octosquares Condensed. Генератор не рисует рекламные буквы; они добавлены отдельными редактируемыми слоями.

- dexscreener-1500x500.png / .jpg — финальные файлы.
- dexscreener-3000x1000.png — растровый мастер.
- dexscreener-editable-master.svg — редактируемые надписи, встроенные изображения и игровой шрифт.
- dexscreener-layered-master.ora — пять растровых слоёв для Krita/GIMP.
- scene-clean-3000x1000.png — сцена без рекламной типографики и знака токена.
- clouds-foreground-generated.png — отдельная генерированная прозрачная полоса облаков.
- layout.json — расположение надписей и бренда.
- verification-report.md, file-verification.json — использованные источники и пределы проверки.

Цельная сценография города и команды создана встроенным image_gen по оригинальным изображениям. Здания и персонажи не вклеиваются отдельными скриншотами. Брендинг наложен точными исходными графическими слоями. Мастер не содержит отдельных 3D-объектов. Ничего не публиковалось.
