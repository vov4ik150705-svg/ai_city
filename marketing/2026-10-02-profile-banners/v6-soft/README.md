# Corporator — мягкий свет

Один дополнительный цветовой вариант одобренной сцены V5: более спокойное утреннее освещение, приглушённые блики и насыщенность. Яркая V5 сохранена отдельно.

Одинаковый арт экспортирован с двумя оформлениями:

- `x-1500x500.png` / `.jpg` — X/Twitter, CORPORATOR и A city worth running.
- `dexscreener-1500x500.png` / `.jpg` — Dexscreener, CORPORATOR, точный оригинальный знак токена и $CORP.
- `scene-clean-3000x1000.png` — чистая сцена без рекламных надписей и логотипа.
- `*-3000x1000.png` — растровые мастера.
- `*-editable-master.svg` — редактируемые рекламные надписи и отдельные слои сцены/брендинга; изображения и шрифты встроены.
- `*-layered-master.ora` — четыре слоя для Krita/GIMP; надписи в ORA растровые, для изменения текста используйте SVG.
- `generation-prompt.txt`, `verification-report.md`, `file-verification.json` — запрос и проверка результата.

Сцена — единый генерированный растровый арт. Исходные игровые изображения используются для проверки идентичности объектов; отдельные изображения персонажей и зданий в баннер не вклеиваются. Точная оригинальная графика бренда добавляется после генерации. Ничего не публиковалось.
