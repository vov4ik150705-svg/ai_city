Норматив — 2,5 с, длинные строки дольше. Ни одна подпись не появляется позже,

## 6. Проверка звука

Музыка и все эффекты — **оригинальный синтез** с нуля, без библиотек и без
чужих записей. Подробности в `AUDIO_SOURCES.md`.

```
Integrated loudness : -15.9 LUFS   (ориентир ≈ -16)
Loudness range      :  4.0 LU
True peak           : -1.7 dBTP   (предел -1)
```

Измерено линейкой EBU R128 (`ffmpeg -filter_complex ebur128=peak=true`), а не
«на слух». SFX в среднем на 18,5 дБ тише музыкальной подложки, без резких
всплесков. Точки SFX расставлены ровно по заданию: 0,0 · 4,0 · 8,0 ·
13,5/14,0/14,5 · 18,5 · 23,5 · 28,0 с. Пять входов персонажей не озвучены пятью
ударами, тиков ровно три, последняя нота затихает естественно внутри 32 с.

**Ограничение, о котором честно говорю:** у меня нет возможности прослушать
дорожку в наушниках на малой громкости, как требует задание. Баланс проверен
измерением и разбором огибающей, а не слухом. Перед публикацией нужен один
человеческий прослушивающий проход — это единственный пункт проверки, который
я не могу закрыть сам.

## 7. Ограничения и принятые решения

1. **Положение острова в сцене 01 — самое спорное место.** Исходник
   `island_hero.png` ровно 16:9, и остров в нём расположен по центру: он занимает
   39,6 % ширины кадра. Формально «остров занимает правую и нижнюю части» при
   целиком помещённом исходнике достижимо только частично. Я сохранил приоритет
   двумя пунктами: в кадр помещён **целый исходник с сохранением пропорций**, и
   при этом наезд доведён до положенных 1.06 без потери пикселей. Остров в итоге
   весит вправо (левый край 714 px, правый отступ 247 px при 1.06), а свободного
   неба слева (714 px) хватает на все четыре строки. Сдвинуть остров ещё правее
   можно было бы только ценой обрезания неба у самого исходника — я этого делать
   не стал. В коде есть проверка `check_island_coverage()`, которая валит сборку,
   если остров хоть раз выйдет за кадр.
2. **Окно с островом в сцене 06.** «Не вырезать его по скалам» я прочитал как
   запрет резать сам остров, а не как запрет убирать пустое небо. Поэтому окно
   640×560 кадрирует только пустое небо: скалы, обод, водопады и облако под
   островом внутри окна целиком, состав острова не изменён, движение 3 % — ровно
   разрешённый максимум.
3. **Далёкие островки в `sky.png`.** На светлом фоне сцен 02–06 видны небольшие
   парящие островки с постройками. Это часть канонического файла
   `assets/background/sky.png`, а не добавленное мной; `VISUAL_DESIGN_SYSTEM.md`
   §12 разрешает дальние парящие островки как окружение. Файл использован целиком
   и без правок. Если владелец считает их лишними на светлом небе — это правка
   фона, а не монтажа.
4. **Agent Hub в сцене 03** стоит сзади слева и частично перекрыт Engineer, как
   задание и описывает. Левая надпись `AGENT HUB` читается полностью, правая
   частично прикрыта фигурой. Задание разрешает убрать его при риске для
   читаемости; я оставил, потому что читаемость титров не пострадала.
5. **Промежуточная ошибка, найденная и исправленная.** Первая сборка держала
   остров с запасом в 0,58 px, и при округлении кадра 0–60 слева появлялась
   чёрная полоса. Пересчитал ограничение и добавил пре-рендер с небом по краям
   плюс проверку в сборке. В сдаваемых файлах полосы нет: чёрных кадров 0 из 960.
6. **Сцены 02→03, 04→05, 05→06 дают один «пустой» кадр неба** на границе. Это
   одинаковый и намеренный вдох между двумя смысловыми блоками, а не пропуск;
   в сцене 03→04 такого кадра нет, потому что роли переходят непрерывно.
7. **Озвучки нет** — так и заказано. **Экспорт в MP4 удался**, ограничений
   среды не возникло: ffmpeg 7.1 с libx264 доступен локально.

## 9. Как пересобрать

```
python -m pip install pillow numpy imageio-ffmpeg
python build/render.py     # 960 кадров -> build/silent.mp4   (~184 с)
python build/audio.py      # music.wav, sfx.wav, mix.wav
python build/finish.py     # мастер, muted, cover.png, контактный лист
python build/verify.py     # параметры файла, кадры, чёрные кадры
python build/motion_audit.py  # разрывы движения и длительность hold
```

Подробности, таблица измеренных силуэтов и ось тайминга — в
`project/RENDER.md`. Сборка детерминирована: те же исходники дают те же 960
кадров.
