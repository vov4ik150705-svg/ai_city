## Подключение

Для desktop: использовать арт целиком, width: 100%, height: auto; пропорция блока 2170 / 342. Размеры img: width=2170, height=342. Не растягивать изображение независимо по двум осям; не использовать cover с обрезкой острова. Текст, кнопки и ссылки — HTML поверх изображения. На ширине 1440 высота изображения около 227 px; на 1920 — 303 px. Мобильная раскладка проверяется отдельно.
